# MPC-BE - Video Player, Playlist Queue, and Renderer List

## About MPC-BE

MPC-BE is a local video player for files you own. MPC-BE Video Player is the window. MPC-BE Playlist Queue is the order. MPC-BE Renderer List is how frames leave. MPC-BE Subtitle Track is captions you chose. MPC-BE Filter Chain is extra filters; keep it short.

Open a file you own. Play it in MPC-BE Video Player. Keep MPC-BE Playlist Queue named. Pick MPC-BE Renderer List you can still name. Turn on MPC-BE Subtitle Track only if you need captions. Add to MPC-BE Filter Chain only for a gap you can name. Stop when the session ends.

MPC-BE Video Player, MPC-BE Playlist Queue, MPC-BE Renderer List, MPC-BE Subtitle Track, and MPC-BE Filter Chain exist to play files you already have a right to play.

Do not point MPC-BE Video Player at a folder you may not play. Do not load every item in MPC-BE Filter Chain. Do not leave MPC-BE Playlist Queue as a dump of the disk. Pick MPC-BE Renderer List you can name. MPC-BE Subtitle Track should stay a track you chose.

## Key Features of MPC-BE

- **Video player as the window** – MPC-BE Video Player is playback. MPC-BE Playlist Queue feeds it. MPC-BE Renderer List paints it. MPC-BE Subtitle Track overlays it. MPC-BE Filter Chain sits under it.
- **Playlist queue as order** – MPC-BE Playlist Queue is files you named. MPC-BE Video Player plays the next. MPC-BE Renderer List unchanged. MPC-BE Subtitle Track can differ per item. MPC-BE Filter Chain should not rewrite the queue.
- **Renderer list as output** – MPC-BE Renderer List is EVR, madVR, or a path you already use. Name it. MPC-BE Video Player then leaves frames there. MPC-BE Playlist Queue still owns order. MPC-BE Subtitle Track still needs a readable output. MPC-BE Filter Chain should not fight the renderer.
- **Subtitle track as captions you chose** – MPC-BE Subtitle Track is a track in the file or a sidecar you own. MPC-BE Video Player shows it. MPC-BE Playlist Queue can remember it. MPC-BE Renderer List still has to composite. MPC-BE Filter Chain is the wrong place for a caption.
- **Filter chain as a short set** – MPC-BE Filter Chain is extra filters. Keep it few. MPC-BE Video Player should still start. MPC-BE Playlist Queue should still play. MPC-BE Renderer List should still output. MPC-BE Subtitle Track should still show.

## Quick Start with MPC-BE

1. **One file** – Open MPC-BE Video Player. Play a file you own. Ignore MPC-BE Playlist Queue. Glance at MPC-BE Renderer List. Ignore MPC-BE Subtitle Track. Ignore MPC-BE Filter Chain.
2. **Queue** – Add three files you own to MPC-BE Playlist Queue. Play in MPC-BE Video Player. MPC-BE Renderer List unchanged. Still no MPC-BE Subtitle Track. Still no extra MPC-BE Filter Chain.
3. **Captions only if needed** – Enable MPC-BE Subtitle Track you chose. Recheck MPC-BE Video Player. MPC-BE Playlist Queue unchanged. MPC-BE Renderer List unchanged. No extra MPC-BE Filter Chain.
4. **Renderer you can name** – Pick one item in MPC-BE Renderer List. Confirm frames in MPC-BE Video Player. MPC-BE Playlist Queue unchanged. MPC-BE Subtitle Track still readable. MPC-BE Filter Chain still short.
5. **Review** – MPC-BE Playlist Queue only files you own. MPC-BE Filter Chain few. MPC-BE Renderer List named. MPC-BE Subtitle Track chosen. MPC-BE Video Player stops with the session. File dated.
